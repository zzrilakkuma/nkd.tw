# 移除 48 小時未付款自動取消

## 目的
訂單進入「等待付款」後，不再因超過 48 小時被系統自動取消。未付款訂單改由管理員手動取消或標記逾期。

## 做法（已選定：整個付款期限一起拿掉）
- 後端：移除背景排程的逾期掃描與付款端點的惰性逾期檢查；核對完成、退回等待付款時不再設定 `payment_deadline`；刪除 `order_expiry.py` 與 `PAYMENT_DEADLINE_HOURS` 設定。
- 排程本身保留，只剩清理 3 個月前的操作紀錄。
- 通知信：移除「付款期限…逾期訂單將自動取消」。
- 前台：移除「我的訂單」倒數與付款頁的 48 小時文案。
- 測試：刪除兩個逾期測試，新增「過了舊期限仍可付款」的測試。

## 考慮過但未採用
- 只停掉自動取消、保留 48 小時提醒與倒數：文案會與實際行為不一致。
- 用設定開關（期限設 0 表示停用）：多留一條不會用到的程式路徑。

## 不做
- 不移除 `expired` 狀態：舊訂單照常顯示，管理員仍可手動標記逾期。
- 不動資料庫欄位 `payment_deadline`，不需要 migration。

## 已知影響
- 未付款訂單會持續佔用保留庫存，直到管理員手動取消。
